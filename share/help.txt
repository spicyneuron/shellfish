Shellfish: https://github.com/spicyneuron/shellfish

A tiny coding agent written in zsh, awk, curl, and jq.

Usage:
  shellfish [OPTIONS] [PROMPT]       Start an interactive chat
  shellfish run [OPTIONS] [PROMPT]   Run exactly one agent turn
  shellfish init                     Write starter config into the Shellfish directory
  shellfish request [-m REF|JSON]    Respond once to the transcript on stdin as JSON
  shellfish decide -m REF|JSON       Answer the decision on stdin as JSON

Run output:
  --json               Print the final result, usage, and session path as JSON
  --jsonl              Stream all turn events as JSON Lines
  --background         Start one detached turn; print its session path

New sessions:
  -p, --profile REF|JSON  Select a profile by name, path, or object
  -m, --model REF|JSON    Select a model file or object; repeats merge
  --sandbox REF|JSON      Merge a sandbox file or object over the profile's
  --system REF|JSON       Append a system file or {"text": "..."}
  -t, --tool REF          Append a tool
  --command REF           Append a command
  --hook REF              Append a hook
  --sandbox-auto          Grant detected development-tool paths

  List options repeat. A REF starting with /, ~/, ./, ../, or @ is a path.

Existing sessions:
  -c, --continue [OPTIONS] [PROMPT]      Continue the most recent session here
  -r, --resume [OPTIONS] [PROMPT]        Pick a session from this directory
  -s, --session PATH [OPTIONS] [PROMPT]  Open a specific session

Shellfish directory:
  SHELLFISH_DIR      Default: nearest .shellfish, else $HOME/.shellfish
  Profiles:          DIR/profiles/NAME.jsonc
  Models:            DIR/models/NAME.jsonc
  Sandbox files:     DIR/sandbox/NAME.jsonc
  Settings:          DIR/.env
  TUI file:          DIR/tui.jsonc
  Sessions:          DIR/sessions/

Authentication:
  Set environment variable or include in the Shellfish directory's .env

  anthropic         ANTHROPIC_API_KEY
  openai_chat       OPENAI_API_KEY
  openai_responses  OPENAI_API_KEY
  openrouter        OPENROUTER_API_KEY
  codex             Uses existing $CODEX_HOME/auth.json

Chat:
  Run /help in chat to list available commands.
