Shellfish: https://github.com/spicyneuron/shellfish

A tiny coding agent written in zsh, awk, curl, and jq.

Usage:
  shellfish [OPTIONS] [PROMPT]       Start an interactive chat
  shellfish run [OPTIONS] [PROMPT]   Run exactly one agent turn

Run output:
  --json               Print the final result, usage, and session path as JSON
  --jsonl              Stream all turn events as JSON Lines
  --background         Start one detached turn; print its session path

New sessions:
  -p, --profile NAME    Select a profile; @default is bundled (repeatable, composes)
  -b, --backend REF     Override the backend adapter reference
  -m, --model MODEL     Override the model
  --request JSON        Merge raw backend request parameters
  --system TEXT         Replace the system prompt (repeatable)
  --system-file PATH    Replace it with file content (repeatable)
  --sandbox-auto        Grant detected development-tool paths
  --sandbox-read PATH   Give sandboxed tools read-only access (repeatable)
  --sandbox-write PATH  Give sandboxed tools read-write access (repeatable)

Existing sessions:
  -c, --continue [OPTIONS] [PROMPT]      Continue the most recent session here
  -r, --resume [OPTIONS] [PROMPT]        Pick a session from this directory
  -s, --session PATH [OPTIONS] [PROMPT]  Open a specific session

Directories:
  SHELLFISH_CONFIG_DIR    Default: ${XDG_CONFIG_HOME:-$HOME/.config}/shellfish
  SHELLFISH_STATE_DIR     Default: ${XDG_STATE_HOME:-$HOME/.local/state}/shellfish
  SHELLFISH_SESSIONS_DIR  Default: STATE_DIR/sessions
  SHELLFISH_SCRATCH_DIR   Default: STATE_DIR/scratch

Global config:
  Profiles:  CONFIG_DIR/profiles/NAME.jsonc
  TUI file:  CONFIG_DIR/tui.jsonc

Authentication:
  Set environment variable or include in the config directory's .env

  anthropic         ANTHROPIC_API_KEY
  openai            OPENAI_API_KEY
  openai-responses  OPENAI_API_KEY
  openrouter        OPENROUTER_API_KEY
  codex             Uses existing $CODEX_HOME/auth.json

Chat:
  Run /help in chat to list available commands.

Full documentation:
